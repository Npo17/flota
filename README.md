# Age of Navies

Juego de barcos: diseñás tu flota con un presupuesto, salís al mar, hundís o abordás barcos, juntás oro y volvés al puerto a mejorar.

Para probarlo en la compu: `python -m http.server 5180` y abrir http://localhost:5180

- `src/config.js`: piezas, precios y enemigos (todo el balance).
- `src/juego.js`: simulación (barcos, balas, bots, abordaje, remolinos, tritones).
- `src/dibujo.js`: lo que se pinta.
- `src/main.js`: pantallas y controles.
